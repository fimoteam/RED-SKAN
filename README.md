# 🛡️ RedScan
RedScan — это легковесный и мощный сканер веб-уязвимостей на Python, предназначенный для автоматизированного сбора информации (enumeration) и поиска распространенных брешей в безопасности.

---

 🚀 Основные возможности

Инструмент выполняет комплексный аудит безопасности в пять этапов:

1.  Анализ HTTP-заголовков: Проверка наличия заголовков безопасности (CSP, HSTS, X-Frame-Options и др.) и выявление утечек версии сервера.
2.  Разбор robots.txt: Автоматическое извлечение скрытых путей, запрещенных к индексации.
3.  Directory Busting: Поиск конфиденциальных файлов и директорий (.env, .git, admin/, backup/ и т.д.).
4.  Error-Based SQL Injection: Тестирование GET-параметров на уязвимость к инъекциям с определением типа СУБД (MySQL, PostgreSQL, MSSQL, Oracle).
5.  Reflected XSS: Проверка параметров на возможность внедрения вредоносных скриптов.
6.  HTML Отчеты: Генерация красивого, интерактивного отчета с результатами сканирования.

 🛠 Установка и запуск

Проект написан с использованием стандартных библиотек Python, поэтому внешние зависимости (pip) не требуются, что делает его максимально портативным.

1.  Клонируйте репозиторий:
    
    git clone https://github.com/fimoteam/RED-SKAN.git
    
    cd redscan
    

3.  Запустите сканер:
    
    # Базовый запуск (цель по умолчанию)
    python main.py

    # Сканирование конкретного URL
    python main.py -u http://example.com -d 0.1

 📊 Отчетность
После завершения работы программа автоматически создает файл redscan_report.html. Отчет включает в себя:
- Цветовую индикацию уровней угрозы (Critical, High, Warning).
- Списки найденных уязвимых параметров и путей.
- Таблицу анализа заголовков.
